    中台门店全量查询#

    查询中台门店管理表的最新全量快照（每店一行，含在营/闭店/解约全状态门店），数据来自 Doris（tll_bi_dw 库，MySQL 协议 9030 端口，经跳板机 SSH 隧道访问）。

    • 数据表：dim_oas_formmain_0145_df（OA 门店主数据日表，日全量分区，仅保留最新一天）
    • 粒度：shop_oneid 门店唯一编码 × 最新分区（每店一行，当前约 11,973 家门店）
    • 取数逻辑：pt = (SELECT MAX(pt)) 取最新天分区，分区内 shop_oneid 天然唯一

    SQL#

    SELECT *
FROM tll_bi_dw.dim_oas_formmain_0145_df
WHERE pt = (
    SELECT MAX(pt)
    FROM tll_bi_dw.dim_oas_formmain_0145_df
)
ORDER BY shop_oneid;

    参数调整#

    • 单店：外层加过滤 AND shop_oneid = 'TLL00010'
    • 按运营状态：外层加过滤 AND busi_status = '营业中'（长期闭店、其它解约 等）
    • 只取常用列：把 * 换成 shop_oneid, shop_id, shop_name, shop_type, busi_status, region_name, prov_name, city_name, district_name, shop_addr, open_date, close_shop_date, pt

    注意事项#

    注意

    pt 为 varchar 天分区（YYYYMMDD），按字符串比较即为时间序，直接 MAX(pt) 即可。该表仅保留最新一个分区，历史快照不落库；门店内部口径仍以 门店信息管理 的 shop_current 为准。

# 渠道对照表

{{< notice warning "两表 ETL 链路不同，本表仅做枚举参考" >}}
- `shop_di`（来源渠道）来自美团 POS 收银系统，受**数据粒度限制**，同一个支付渠道分不清来自哪个入口（POS / 自营外卖 / 小程序），ETL 只能模糊归并
- `shop_pay_channel_di`（支付渠道）来自自研收银 + `channel_mapping` 配置，归并更精细
- 下面的对照表**不是严格的一对一映射**，不要用来跨表 JOIN
- 后续全切自研 POS 后，渠道名会逐步收敛
{{< /notice >}}

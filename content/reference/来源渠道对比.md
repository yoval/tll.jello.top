# 来源渠道：门店销售 vs 商品销售

两张表都在**来源渠道口径**下，粒度相同（门店 × 日期 × 渠道），对比 `total_amount`（门店流水）与 `dp_total_amount`（商品流水）的差异。

| 表 | 对比字段 | 含义 |
|---|---|---|
| `ads_dbs_trade_shop_di` | `total_amount` | **门店销售**：门店口径流水，含商品 + 配送费 + 包装费 |
| `ads_dbs_trade_food_di` | `dp_total_amount` | **商品销售**：纯商品流水，不含配送费、包装费 |

{{< notice info "渠道完全相同" >}}
两表渠道集完全一致（都是 14 条，到家 4 + 到店 10），可以直接按 `channel_name` JOIN。
{{< /notice >}}

## SQL

```sql
-- shop_di：门店销售
SELECT DATE_FORMAT(business_date, '%Y-%m') AS 月份,
       channel_name                       AS 渠道,
       SUM(total_amount)                  AS 门店流水
FROM tll_bi_dw.ads_dbs_trade_shop_di
WHERE business_date LIKE '2026%'
GROUP BY 月份, 渠道 ORDER BY 月份, 渠道;
```

```sql
-- food_di：商品销售
SELECT DATE_FORMAT(business_date, '%Y-%m') AS 月份,
       channel_name                       AS 渠道,
       SUM(dp_total_amount)               AS 商品流水
FROM tll_bi_dw.ads_dbs_trade_food_di
WHERE business_date LIKE '2026%'
GROUP BY 月份, 渠道 ORDER BY 月份, 渠道;
```

## 口径差异与换算系数

shop_di 的 `total_amount` 包含**配送费、包装费**等门店侧流水，而 food_di 的 `dp_total_amount` 只统计商品本身流水。这是两表差异的根本原因。

### 按渠道类型

| 渠道类型 | 配送费/包装费 | 差异率 |
|---|---|---|
| **到家（外卖）** | ✅ 有 | **+6~9%** |
| **到店** | ❌ 无 | **±0.4%** |

### 外卖换算口诀

到家渠道（美团/淘宝闪购/自营/京东），**商品流水 ≈ 门店流水 × 93%**：

| 系数 | 含义 |
|---|---|
| shop × 93% ≈ food | 门店流水 → 商品流水（打 93 折） |
| food × 1.08 ≈ shop | 商品流水 → 门店流水 |
| 7% 左右 | 配送费+包装费占 shop_di 的比例 |

每月换算系数在 91% ~ 94% 之间波动，全年稳定在 93%。

## 注意事项

{{< notice warning "注意" >}}
1. 到家渠道（外卖）shop_di > food_di 是正常现象，差额来自配送费、包装费。
2. 到店渠道差异 ±0.4% 属于数据波动，可视为一致。
3. 两表渠道名完全相同，可以直接 JOIN。
{{< /notice >}}

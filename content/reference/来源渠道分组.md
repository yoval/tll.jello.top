## 按大渠道聚合

大渠道只有 **到店 / 到家** 两档：

```sql
SELECT
    CASE
        WHEN channel_name IN ('美团外卖', '京东外卖', '自营外卖', '淘宝闪购')
            THEN '到家'
        ELSE '到店'
    END                    AS 大渠道,
    SUM(dp_total_amount)   AS 商品流水
FROM tll_bi_dw.ads_dbs_trade_food_di
WHERE business_date >= 20261001 AND business_date <= 20261031
GROUP BY 大渠道
ORDER BY 商品流水 DESC;
```

到店包含 pos、小程序、团购（`pos收银`、`甜啦啦小程序`、`微信小程序`、`支付宝小程序`、`小程序`、`抖音团购`、`抖音小程序（核销工具）`、`高德团购`、`快手团购`、`美团在线点`、`美团/大众点评团购`）；到家包含外卖（`美团外卖`、`京东外卖`、`自营外卖`、`淘宝闪购`）。

## 注意事项

{{< notice info "与支付渠道分组不是一套" >}}
本页是 `channel_name`（来源渠道）的归并，用于 `shop_di` / `food_di`。

`ads_dbs_trade_shop_pay_channel_di.payment_channels`（原始支付渠道）是另一套枚举，条目更多且互不对应，归并规则见 [支付渠道分组]({{< ref "/reference/渠道分组" >}})。

两套枚举的大渠道口径一致，都是 **到店 / 到家**。
{{< /notice >}}

{{< notice warning "自营外卖归入京东外卖" >}}
`自营外卖` 在中渠道层归入「京东外卖」，大渠道是 **到家**。与美团外卖、淘宝闪购同组，不影响汇总口径。
{{< /notice >}}

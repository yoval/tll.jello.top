# 月度数据概览

基于同比结果库与门店底表的 Excel Power Query 报表工作台，面向管理层提供月度经营概览。

## 数据来源

| Power Query 查询 | 数据源 |
|---|---|
| 期数 / 门店底表 | `multi_period_channel_summary.期数` / `全量数据`（由 [多时段渠道同比分析]({{< ref "/projects/monthly/多时段渠道同比分析" >}}) 生成） |
| 门店信息 | `Tianlala.shop_current`（由 [门店信息管理]({{< ref "/projects/daily/门店信息管理" >}}) 每日重建） |

## 使用方式

1. 先运行多时段渠道同比项目，确保本期/同期数据已写入 MySQL
2. 打开当月概览 xlsx，「数据 → 全部刷新」
3. `本期_`/`同期_` 开头的指标列在 M 代码中强制转为 number，避免上游类型漂移

## 字段映射

经理层级在查询中统一重命名：一级经理→省区经理、二级经理→区域经理、三级经理→督导，与各报表口径保持一致。

# 小程序税务报送

面向税务机关的两张报送表生成工具：《平台内经营者和从业人员身份信息报送表》与《收入信息报送表》，生成 CSV 后自动用 7-Zip AES-256 加密压缩。

- **数据依赖**：
  - 执照库 `license_manage`（[门店营业执照管理]({{< ref "/projects/manage/门店营业执照管理" >}}) 维护），提供报送名称与统一社会信用代码
  - 门店信息 `shop_info` / `shop_current`（[门店信息管理]({{< ref "/projects/daily/门店信息管理" >}}) 每日重建）
  - 本期报税表 `输入/小程序报税表_图表1.xlsx`

## 数据链路

```text
输入/小程序报税表_图表1.xlsx
→ license_manage.platform_tax_report（replace 全量重建）
→ 匹配 license_store_license、shop_info/shop_current，剔除特殊门店
→ 输出 收入信息 / 人员身份信息 CSV → 同名加密 zip
```

## 运行方式

```bash
python main.py upload     # 1. 导入本期报税表
python main.py person     # 2. 身份信息表（21 列，一店一行）
python main.py revenue    # 3. 收入信息表（27 列，同店多周期先汇总）
python main.py all        # 依次执行全部（默认）
python main.py revenue --no-zip   # 只出 CSV 不压缩
```

## 报送规则要点

- 报送范围：当期有收入的门店；两张表均剔除 `license_special_store` 特殊门店（学校店/景区店/测试店）
- 名称/统一社会信用代码取执照表最新版本（`is_latest=1`）
- 唯一标识码 = `{门店编号}_{version}`，两张表保持一致
- 联系人/电话取 `shop_info` 最新记录；经营开始时间取最早记录
- 已解约门店状态填 `03|退出`，否则 `01|新增`

## 注意事项

- 压缩密码在 `config.ini [Archive].password`，留空则只打包不加密
- 表头从 `模板/` 官方文件动态读取，模板升级无需改代码
- 运行结束的 WARNING 汇总需人工核对：报送名称为空、未匹配执照、未匹配门店记录

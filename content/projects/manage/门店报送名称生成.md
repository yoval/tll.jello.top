# 门店报送名称生成

依据 `license_store_license` 表的注册地址，调用 DeepSeek 大模型批量生成门店报送名称（如 `安徽省宿州市灵璧县…颐高国际电商园…` → `安徽宿州灵璧颐高国际电商园店`），校验后回写 MySQL。

- **数据依赖**：执照库 `license_store_license`（注册地址、报送名称），由 [门店营业执照管理]({{< ref "/projects/manage/门店营业执照管理" >}}) 维护

## 命名规范（沉淀自 9000+ 条真实记录）

1. 格式：省简称 + 市 + 区/县 + 显著地标/道路/乡镇 + 店，尽量 ≤ 25 个汉字，一律以「店」结尾
2. 长区划用通称（新疆、内蒙古、北京、上海…），自治州/盟用通称（新疆伊犁、四川凉山…）
3. 地标优先：商场/园区/学校/医院/车站/景区 > 道路/乡镇/街道
4. 去冗余：门牌号、栋幢单元楼层、方位距离、括号注释
5. 地址缺信息时不臆造，只保留地址中已出现的部分

## 运行方式

```bash
pip install pymysql requests

# 预览（不写库）
python generate_report_name.py --dry-run --limit 50
# 全量处理并回写
python generate_report_name.py
# 只处理每店最新版本
python generate_report_name.py --last-vision
# 输出 TSV 人工复核后回写
python generate_report_name.py --out names.tsv --limit 200
python batch_runner.py apply
```

## 关键行为

- 待处理行 = 报送名称为空 且 注册地址非空；`skip.txt` 中的 id 自动排除
- 模型输出统一清洗（以「店」结尾、去空白重复），校验长度与残留房号，不合格只告警不上库
- 批处理断点续做，写库失败整批放弃，重跑不重复

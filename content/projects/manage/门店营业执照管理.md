# 门店营业执照管理

门店营业执照批量 OCR 识别、按统一社会信用代码走风鸟校验企业信息的 **Web 管理系统**（Flask），数据写入独立库 `license_manage`，含第三方 API 调用统计与后台任务历史。

- **相关项目**：执照库 `license_manage` 被 [门店报送名称生成]({{< ref "/projects/manage/门店报送名称生成" >}})、[小程序税务报送]({{< ref "/projects/monthly/小程序税务报送" >}}) 使用

## 核心功能

1. **执照图片本地化**：下载到 `data/licenses/{门店编号}`，OCR 一律识别本地文件，不依赖图床与 OA cookie 时效
2. **OCR 识别**：腾讯云 / 百度智能云双平台、多账号，识别统一社会信用代码 / 执照名称 / 经营者
3. **风鸟校验**：按统一社会信用代码查询工商信息；风鸟返回的正确号码优先采信，可自动纠正 OCR 错号；限速约 5 秒/条，触发上限自动暂停约 1 小时后续跑
4. **版本化管理**：门店执照以版本行存储（`is_latest` 标记最新），更换链接就地改写不开新版本，换执照内容追加新版本
5. **导出**：按「生效值」（校验 > OCR，可手动指定）导出营业执照汇总 xlsx
6. **调用统计 / 任务历史**：接口 × 账号维度的费用监控，任务进度持久化在本地 SQLite

## 运行方式

```bash
pip install -r requirements.txt
python app.py                # http://127.0.0.1:5000
python app.py --port 8000    # 自定义端口
```

## 注意事项

- OA cookie 只在下载执照图片时使用（`data/cookies_oa.json`，浏览器导出覆盖）；风鸟账号 cookie 有效期数月，新增账号需在 `config/settings.py` 的 `CHECK_CONFIG` 中登记
- `config/settings.py` 含云密钥与数据库口令，仓库为私人仓库，**不得公开**
- 数据库备份：`python db/backup_db.py`（优先 mysqldump），恢复加 `--restore`

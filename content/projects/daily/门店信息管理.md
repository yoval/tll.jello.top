# 门店信息管理

门店信息 Excel 的数据清洗、SCD 历史追踪、组织架构自动推断、修复生成与格式化导出工具。

- **项目仓库**：<https://e.coding.net/fuwenyue/tianlala/store_info_format.git>
- **相关项目**：经 [定时任务工作台]({{< ref "/projects/定时任务工作台" >}}) 的 DailyMenu 手动触发；`shop_current` 被 [多时段渠道同比分析]({{< ref "/projects/monthly/多时段渠道同比分析" >}})、[周边数据分析]({{< ref "/projects/monthly/周边数据分析" >}})、[月度数据概览]({{< ref "/projects/monthly/月度数据概览" >}})、[小程序税务报送]({{< ref "/projects/monthly/小程序税务报送" >}}) 引用

## 数据表

| 表名 | 作用 | 模式 |
|---|---|---|
| `shop_info` | 原始门店数据，完整历史 | SCD |
| `shop_current` | 修复后的当前门店状态 | 每日 replace 重建 |
| `shop_org_hierarchy` | 组织架构层级映射 | 每日 replace 重建 |
| `shop_region_mapping` | 省/市/区 → 经理映射 | 每日 replace 重建 |

## 处理流程

```text
门店-可导出.xlsx → 清洗 → 写入 shop_info（SCD）
→ 从在营门店推断组织架构（战区/一级/二级/三级经理，冲突按门店数多者为准）
→ 已解约门店按地区匹配经理、直营店 ZYD 特殊处理 → 层级归并
→ 写入 shop_current → 导出 增量门店管理表_YYYYMMDD_HHMM.xlsx
```

## 运行方式

```bash
# 输入底表放入 Downloads/门店-可导出.xlsx，配置 config.ini 后执行
python main.py
```

企业微信机器人推送当前已暂停（代码中注释），检查通过后可手动启用。

## 注意事项

- 每次运行都会更新 `shop_info` SCD 记录并**重建** `shop_current`
- 经理命名内部统一为 一级/二级/三级经理，对应业务口径 大区/省区/区域经理（督导），输入输出自动映射
- OA 门店管理表无历史记录，历史状态以本项目的 `shop_info` 为准

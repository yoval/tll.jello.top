# 标准菜品名称核对

对比总部「菜品库」导出的菜品与「标准单品名称」库，找出两边不一致的菜品，输出含两个 sheet 的 Excel 核对结果，用于在 OA / 美团两侧补齐菜品名称。

- **项目仓库**：<https://e.coding.net/fuwenyue/tianlala/standard_food.git>
- **相关项目**：经 [定时任务工作台]({{< ref "/projects/定时任务工作台" >}}) 的 DailyMenu 触发；输入依赖 OA「标准单品名称」库与总部「菜品库」导出

## 输入文件

两个文件均放在 `SOURCE_DIR`（默认 `C:\Users\Administrator\OneDrive\Tianlala\temp`）：

| 文件 | sheet | 说明 |
|---|---|---|
| 文件名含「菜品库」的 xlsx | 总部菜品 | 匹配到多个时取修改时间最新的一个 |
| `标准单品名称.xlsx` | 标准单品名称 | 固定文件名 |

文件顶部的说明行由脚本按表头关键字自动定位，无需手工删行。

## 处理逻辑

1. 读取总部菜品，按「菜品名称」去重，过滤基础分类含 `测试`、`下架`、`套餐` 的行
2. 读取标准单品名称，检测重复项
3. 按菜品名称做双向集合对比：
   - 总部菜品有、标准库没有 → `OA缺失`
   - 标准库有、总部菜品没有 → `美团缺失`

## 运行方式

```bash
python main.py
```

结果 `标准菜品名称核对结果.xlsx` 输出到脚本所在目录，控制台打印各环节条数与输出路径。

一次性的产品名称标准化清洗见 [标准菜品名称清洗]({{< ref "/projects/标准菜品名称清洗" >}})。

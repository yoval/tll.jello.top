# 定时任务工作台

本机通过 Windows 任务计划程序注册的开机延迟任务，以及统一的日常任务交互菜单。

## 开机任务时间线

触发方式均为系统启动后延迟执行：

| 延迟 | 任务名 | 执行内容 | 角色 |
|---|---|---|---|
| +1 min | `KeepMySQLAlive` | `wscript keep_mysql_alive.vbs` | 后台拉起 WSL2 MySQL 容器常驻 |
| +2 min | `ClearDownloads` | `clear_downloads.bat` | 清空下载文件夹 |
| +5 min | `DailyMenu` | `daily.bat` | 弹出日常任务菜单，手动选择执行 |
| +10 min | `BeisengUsersDaily` | `python main.py` | 自动同步北森通讯录 |

XML 配置文件均保留在项目目录，重装系统后可用：

```powershell
schtasks /Create /TN <任务名> /XML <文件.xml> /F
```

## 常用管理命令

```powershell
schtasks /Query /TN "BeisengUsersDaily" /V /FO LIST   # 查看任务
schtasks /Run   /TN "DailyMenu"                       # 立即运行
schtasks /Change /TN "KeepMySQLAlive" /Disable        # 禁用
schtasks /Delete /TN "KeepMySQLAlive" /F              # 删除（需管理员）
taskschd.msc                                          # 图形界面
```

彻底停止 MySQL：`wsl --shutdown`（WSL 虚拟机关闭，容器随之停止）。

# 加盟店每日各渠道流水

按月筛选加盟店每日大渠道流水（pos / 小程序 / 团购 / 外卖），渠道映射口径同 [渠道分组]({{< ref "/reference/渠道分组" >}})。

- **数据表**：[ads_dbs_trade_shop_pay_channel_di]({{< ref "/data-dictionary/ads/ads_dbs_trade_shop_pay_channel_di" >}})
- **粒度**：日期 × 大渠道（加盟店 `shop_id LIKE 'TLL%'`）
- **指标**：`SUM(amount)` 流水金额

## SQL

```sql
SELECT
    pt AS 日期,
    CASE
        WHEN payment_channels = 'pos收银' THEN 'pos'
        WHEN payment_channels IN (
            '甜啦啦小程序',
            '甜啦啦小程序-储值业务',
            '微信小程序',
            '支付宝小程序'
        ) THEN '小程序'
        WHEN payment_channels IN (
            '抖音团购',
            '线上新增抖音团购',
            '抖音小程序（核销工具）',
            '高德团购',
            '快手团购',
            '线上新增快手团购',
            '美团/大众点评团购',
            '美团/大众点评小程序',
            '线上新增美团团购',
            '美团在线点'
        ) THEN '团购'
        WHEN payment_channels IN (
            '饿了么外卖',
            '淘宝闪购',
            '京东外卖',
            '美团外卖'
        ) THEN '外卖'
        ELSE payment_channels
    END AS 渠道,
    SUM(amount) AS 流水
FROM ads_dbs_trade_shop_pay_channel_di
WHERE pt LIKE '202610%'
    AND shop_id LIKE 'TLL%'
GROUP BY pt, 渠道
ORDER BY pt, 渠道;
```

## 参数调整

- **换月份**：修改 `pt LIKE '202610%'` 中的年月部分，如 `'202611%'`
- **单月精确范围**：改为 `pt >= 20261001 AND pt <= 20261031`（`pt` 为整数，不要加引号）
- **含直营店**：放宽门店过滤为 `AND (shop_id LIKE 'TLL%' OR shop_id LIKE 'ZYD%')`

## 注意事项

{{< notice warning "注意" >}}
- `pt` 为整数类型，`LIKE '202610%'` 在 MySQL 中可用（整数会被隐式转字符串），但严谨写法建议用范围条件。
- 渠道分组可能新增 `线上新增xx团购` 等原始渠道，运行前检查 `ELSE` 分支是否产出未识别渠道；完整映射表见 [渠道分组]({{< ref "/reference/渠道分组" >}})。
{{< /notice >}}

# 全量门店查询

查询每个门店编号的最新一条记录（含在营与已解约的全量门店）。数据来自门店信息 SCD 表，每次门店信息变更新增一行，`start_date / end_date` 标记版本有效期。

- **数据表**：`Tianlala.shop_info`（原始门店数据，完整历史，约 **120,398 行 / 11,956 个门店**）
- **粒度**：门店编号 × 最新记录行（每店一行）
- **主键**：`(门店编号, start_date)` —— SCD 版本表，不是 `(门店编号)`
- **取数逻辑**：按门店分组取 `MAX(end_date)` 关联回原表

## 实测分布

| 指标 | 值 |
|---|---|
| 总行数 | 120,398 |
| 去重门店数 | 11,956 |
| `end_date IS NULL` 行数 | **0**（所有版本行都有截止日期） |
| `is_current = 1` 行数 | 7,329（在营门店） |
| **全量最新行中 `is_current = 0`** | **4,627**（已解约/闭店门店的最新记录） |
| 同店同 `end_date` 多行 | **0**（无重复，JOIN 安全） |

{{< notice warning "为什么不用 is_current = 1" >}}
`is_current = 1` 只能取到 7,329 家在营门店，**漏掉约 4,627 家已解约/闭店门店的最新记录**。查全量最新行必须用 `MAX(end_date)`。`is_current = 0` 的 4,627 条就是这些已闭店门店的"当前"状态行——它们没有下一个版本，所以 `is_current` 始终是 0。
{{< /notice >}}

## SQL

```sql
-- MySQL 5.7 / Doris 兼容写法（子查询 JOIN）
SELECT s.*
FROM Tianlala.shop_info s
JOIN (
    SELECT 门店编号, MAX(end_date) AS max_end
    FROM Tianlala.shop_info
    GROUP BY 门店编号
) m ON s.门店编号 = m.门店编号 AND s.end_date = m.max_end
ORDER BY s.门店编号;
```

```sql
-- MySQL 8+ / Doris 更清晰写法（窗口函数）
SELECT * FROM (
    SELECT s.*,
           ROW_NUMBER() OVER (PARTITION BY s.门店编号 ORDER BY s.end_date DESC) AS rn
    FROM Tianlala.shop_info s
) t
WHERE t.rn = 1
ORDER BY t.门店编号;
```

## 常用字段

| 分类 | 字段 |
|---|---|
| 标识 | 门店编号、门店名称、U8C客商编码 |
| 加盟属性 | 门店类型（加盟/直营）、运营状态（营业中/短期闭店/长期闭店/签约/已解约…） |
| 地理 | 省、市、区、门店详细地址 |
| 运营 | 战区、一级经理、二级经理、三级经理、收银机ID、发货仓库 |
| 法人 | 法人、法人电话、法人身份证号码 |

运营状态取值：营业中、短期闭店、签约、长期闭店、空合同、其它解约、强制解约、到期解约（约 2,700 家已解约门店）。

## 参数调整

- **仅在营门店**：外层加 `WHERE s.is_current = 1`（约 7,329 家，或者用 `WHERE 运营状态 = '营业中'` 更直观）
- **单店**：外层加 `WHERE s.门店编号 = 'TLL00001'`
- **按战区**：外层加 `WHERE s.战区 = 'XX战区'`
- **按省**：外层加 `WHERE s.省 = '浙江省'`
- **加盟/直营**：外层加 `WHERE s.门店类型 = '加盟'`（或 `'直营'`）

## 注意事项

{{< notice warning "注意" >}}
1. `end_date` 在本表里**全非 NULL**，`MAX(end_date)` 逻辑可靠。如果以后 ETL 改成用 `end_date IS NULL` 标记当前版本，那 SQL 要先 `COALESCE(end_date, '9999-12-31')` 再 MAX。
2. 同店同 `end_date` 多行实测为 0，当前 JOIN 写法安全；如果以后版本表出现同店同截止日多版本，窗口函数写法（`ROW_NUMBER() OVER ORDER BY end_date DESC, start_date DESC`）更稳。
{{< /notice >}}

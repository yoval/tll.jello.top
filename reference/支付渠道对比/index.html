    来源渠道 vs 支付渠道 对比分析#

    对比 ads_dbs_trade_shop_di（来源渠道 channel_name）与 ads_dbs_trade_shop_pay_channel_di（支付渠道 payment_channels）。

    两表总额几乎完全一致（差异 < 0.05%），但渠道字段的定义不同：

    表 字段 含义 渠道数
    shop_di channel_name 订单来源（订单从哪来） 14
    shop_pay_channel_di payment_channels 支付/核销方式（用户怎么付的） 18

    SQL#

    -- shop_di：来源渠道
SELECT DATE_FORMAT(business_date, '%Y-%m') AS 月份,
       channel_name AS 渠道,
       SUM(total_amount) AS 流水
FROM ads_dbs_trade_shop_di
WHERE business_date LIKE '2026%'
GROUP BY 月份, 渠道 ORDER BY 月份, 渠道;

-- shop_pay_channel_di：支付渠道
SELECT DATE_FORMAT(pt, '%Y-%m') AS 月份,
       payment_channels AS 渠道,
       SUM(amount) AS 流水
FROM ads_dbs_trade_shop_pay_channel_di
WHERE pt LIKE '2026%'
GROUP BY 月份, 渠道 ORDER BY 月份, 渠道;

    各月汇总差异#

    两表总额完全对得上，10 个月差异率均在 ±0.1% 以内，全年仅 -0.03%。

    月份 差异率（shop - pay）
    01 -0.01%
    02 -0.04%
    03 -0.00%
    04 +0.01%
    05 -0.01%
    06 +0.02%
    07 -0.09%
    08 -0.07%
    09 -0.08%
    10 -0.04%
    全年 -0.03%

    7-9 月差异稍大（-0.07% ~ -0.09%），可能与团购核销方式季节性波动有关，但绝对额仅几十万，可视为数据正常波动。

    渠道映射关系#

    完全一致（5 个）#

    两边渠道名相同，流水完全一致：

    渠道 shop_di pay_channel
    微信小程序 ✓ ✓
    支付宝小程序 ✓ ✓
    美团外卖 ✓ ✓
    高德团购 ✓ ✓
    美团在线点 ✓ ✓

    合并/拆分（2 组）#

    shop_di 把多个支付渠道合并为一个来源渠道：

    shop_di（来源） pay_channel（支付） 说明
    自营外卖 + 京东外卖 京东外卖 pay 合并了自营和京东的流水
    小程序（汇总） 甜啦啦小程序 + 甜啦啦小程序-储值业务 shop 把多个小程序入口合并

    同名异值（4 个）#

    渠道名相同但流水差异巨大，shop_di 的 pos 收银包含了这些渠道的 POS 核销部分：

    渠道 shop_di pay_channel 差异倍数 原因
    抖音团购 小 大 13× shop 大部分归 pos
    美团/大众点评团购 小 大 14× shop 大部分归 pos
    快手团购 极小 大 shop 大部分归 pos
    抖音小程序（核销工具） 小 大 10× shop 大部分归 pos

    pos收银 是两张表差异最大的渠道：shop_di 比 pay_channel 多出约 1.2 亿，正好对应上述团购/核销渠道的差额——shop 把通过 POS 核销的团购券归为 pos收银，而 pay_channel 直接归为团购渠道。

    shop_di 独有 vs pay_channel 独有#

    shop_di 独有 pay_channel 独有
    自营外卖 甜啦啦小程序、甜啦啦小程序-储值业务
    小程序 线上新增抖音团购、线上新增快手团购、线上新增美团团购
    美团/大众点评小程序

    口径差异总结#

    维度 shop_di（来源渠道） pay_channel（支付渠道）
    本质 订单从哪里来 用户怎么付钱
    pos收银 含团购核销部分 仅 POS 直接收款
    小程序 一条汇总 拆为甜啦啦/微信/支付宝/美团/抖音
    外卖 自营 + 京东 分开 合并为一条京东外卖
    团购 小额（仅非 POS 核销） 全额

    注意事项#

    注意
    1. 两表总额一致（< 0.05% 差异），但渠道不可直接按名称对比。
    2. 团购/核销类渠道 shop_di 大幅偏小，差额计入 pos收银。
    3. 需要对应口径时参考上方映射关系表。

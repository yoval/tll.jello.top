    来源渠道对比分析（shop_di vs food_di）#

    对比 ads_dbs_trade_shop_di（门店销售汇总）与 ads_dbs_trade_food_di（产品销售）的按月按渠道流水。

    两表渠道名存在差异（见 数据字典），shop_di 的小程序为汇总一条，food_di 拆分为微信/支付宝两条。

    SQL#

    -- shop_di：门店汇总流水 total_amount
SELECT 
    DATE_FORMAT(business_date, '%Y-%m') AS 月份,
    channel_name AS 渠道,
    SUM(total_amount) AS 流水
FROM ads_dbs_trade_shop_di
WHERE business_date LIKE '2026%'
GROUP BY 月份, 渠道
ORDER BY 月份, 渠道;
    -- food_di：商品流水 dp_total_amount
SELECT 
    DATE_FORMAT(business_date, '%Y-%m') AS 月份,
    channel_name AS 渠道,
    SUM(dp_total_amount) AS 流水
FROM ads_dbs_trade_food_di
WHERE business_date LIKE '2026%'
GROUP BY 月份, 渠道
ORDER BY 月份, 渠道;

    按月汇总差异率（2026 年 1-10 月）#

    shop_di 始终高于 food_di，差异率波动在 1.9% ~ 3.2%，全年平均 +2.4%。8 月差异率最高，5 月最低。

    口径差异与换算系数#

    shop_di 的 total_amount 包含配送费、包装费等门店侧流水，而 food_di 的 dp_total_amount 只统计商品本身流水。这是两表差异的根本原因。

    按渠道类型#

    渠道类型 配送费/包装费 差异率
    到家（外卖） ✅ 有 +6~9%
    到店 ❌ 无 ±0.4%

    外卖换算口诀#

    到家渠道（美团/淘宝闪购/自营/京东），food_di ≈ shop_di × 93%：

    系数 含义
    shop × 93% ≈ food 门店流水 → 商品流水（打 93 折）
    food × 1.08 ≈ shop 商品流水 → 门店流水
    7% 左右 配送费+包装费占 shop_di 的比例

    每月换算系数在 91% ~ 94% 之间波动，全年稳定在 93%。

    注意事项#

    注意
    1. shop_di 的 小程序 与 food_di 的 微信小程序 + 支付宝小程序 口径不同，对比时需先统一。
    2. 到家渠道（外卖）shop_di > food_di 是正常现象，差额来自配送费、包装费。
    3. 到店渠道差异 ±0.4% 属于数据波动，可视为一致。

    常用术语#

    部门日常数据工作中高频术语的口径说明。

    经营指标#

    术语 含义 对应字段
    GMV / 流水 订单商品原价总金额，未扣优惠 amount / dp_total_amount
    实收 用户实际支付金额，流水 − 优惠 income / dp_pay_amount
    优惠 平台与商家让利合计 discount / dp_discount_amount
    订单数 / 订单量 支付订单笔数 order_cnt / dp_order_count
    销量 商品销售件数 dp_item_count
    营业天数 统计期内当日流水（或销量）大于 0 的天数，需用 COUNT(DISTINCT CASE WHEN …) 严格判断 —
    动销门店 本期流水 > 0 的门店（统计期内有流水） —
    存量门店 本期流水 × 对比期流水 > 0 的门店，即两期均有流水 —
    全量门店 本期流水 + 对比期流水 > 0 的门店，即至少一期有流水 —
    增量门店 OA 解约门店数据不再更新导致同比缺失，由 门店信息管理 脚本维护补充 —
    同比 本期与去年同期对比，如 2026 年 10 月对比 2025 年 10 月 —
    渗透率 产品售卖天数 ÷ 门店营业天数（周边报表口径） —

    渠道#

    术语 含义
    大渠道 第一级渠道分类：pos小程序、线上团购、线上外卖
    中渠道 第二级分类，如 抖音团购、美团外卖
    原始渠道 中台 payment_channels 字段的原始取值，如 线上新增抖音团购

    三级渠道的完整对照见 渠道分组。中台每月可能出现 线上新增xx团购 等新原始渠道，出报表前需先做渠道覆盖检测。

    门店与组织#

    术语 含义
    加盟店 加盟门店，门店编号以 TLL 开头
    直营店 / ZYD 直营门店，门店编号以 ZYD 开头
    战区 南北战区，最高营运分区
    省区经理 内部表中称「一级经理 / 大区经理」
    区域经理 内部表中称「二级经理 / 省区经理」
    督导 内部表中称「三级经理 / 区域经理」

    经理层级在不同系统中命名不一致，shop_current 内部统一为一级/二级/三级经理，Power Query 报表输出时重命名为省区/区域/督导。

    商品#

    术语 含义
    单品 普通饮品，item_type = 单品
    套餐 组合商品，tc_ 开头字段
    小料 饮品加料，xl_ 开头字段
    周边 零食事业部周边产品，zb_ 开头字段，分类取 周边产品/周边
    标准菜品名称 OA 维护的标准单品名称，用于归并中台不规范商品名，见 标准菜品名称核对
    报货 门店向供应链下的采购订单，报货金额以财务部统计为准

    数据工程#

    术语 含义
    中台 公司数据中台（tll_bi_dw 等库），只能经 JumpServer 访问，有导出量限制
    JumpServer 中台数据库的跳板机，SQL 查询与数据导出入口
    OA 泛微 OA 协同系统，门店管理表、标准单品名称等主数据的维护入口
    北森（italent） HR 系统，通讯录与入离职数据来源
    SCD / SCD2 缓慢变化维 Type 2：每次属性变更保留旧版本行并新增新版本行，is_current 标记当前版本（如 beiseng_users、shop_info）
    分区字段 pt 日分区，格式 yyyyMMdd，门店表中为整数类型，写条件时不加引号
    replace 重建 每次运行 DROP 后全量重建目标表，非增量追加
    小料 支付渠道分组

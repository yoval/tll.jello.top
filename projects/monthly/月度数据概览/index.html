    月度数据概览#

    面向管理层的月度经营概览 Excel 工作台。每月底按本期 vs 同期两期对比，含门店维度（渠道 × 经理层级 × 运营状态）和产品维度（销量 × 流水 × 标签）。

    产物位置
    • Excel 文件：C:\Users\Administrator\OneDrive\Script\Monthly\数据概览\{月份}月概览数据.xlsx（每月换文件名）
    • 操作顺序：先产出三张表 → 再刷新 Excel → 月底交付

    依赖关系（三个数据源）#

    Excel 里的三个 Power Query 查询分别从三张表拉取：

    # 数据源 生产项目
    ① multi_period_channel_summary.期数 + .全量数据 多时段渠道同比分析
    ② Tianlala.shop_current 门店营业执照管理（每日重建）
    ③ Tianlala.food_sales_summary food_sales 脚本（目录：C:\Users\Administrator\OneDrive\Script\Monthly\food_sales）

    每月操作步骤#

    假设本期 202611、同期 202511。Step 1~3 可并行，全部完成后再做 Step 4。

    Step 1：生成 multi_period_channel_summary#

    详见 多时段渠道同比分析。简述：

    1. 改 config.yaml 的 periods：20261101~20261130, 20251101~20251130
    2. python main.py → DROP + 重建三张表（期数、全量数据、存量数据）

    Step 2：确认 shop_current 已重建#

    详见 门店营业执照管理。这个是每日重建的，跑 sync_shop_data 即可，不用特地为概览数据做什么。

    Step 3：生成 food_sales_summary（产品侧，需手动）#

    仅给本 Excel 用，其他项目不消费。脚本目录 C:\Users\Administrator\OneDrive\Script\Monthly\food_sales。

    3.1 跑「产品销售唯一值」SQL → 手动映射标准名称#

    在 Doris 上执行（改 WHERE 里的两个月份）：

    SELECT
    item_name,
    SUM(dp_item_count) AS 销量
FROM tll_bi_dw.ads_dbs_trade_food_di
WHERE LEFT(business_date, 6) IN ('202511', '202611')
  AND (dp_item_count > 0 OR dp_total_amount > 0)
GROUP BY item_name
ORDER BY 销量 DESC;
    手动映射两列

    导出为 data/产品销售唯一值.xlsx，手动添加两列：

    列 内容
    标准名称 不合法/别名 → 手动改成标准名；已是标准名则原值填入
    类型 奶茶 / 果茶 / 冰淇淋 / 周边 / 小料 / …（手动分类）

    脚本里 enrich_csv() 用这张表的 item_name → 标准名称 / 类型 做映射。映射不全会导致未匹配产品被归入「其它」，每月要核对新增。

    3.2 跑「产品销售明细」SQL → 导出 CSV#

    SELECT
    LEFT(business_date, 6)    AS 月份,
    item_name                 AS 商品名称,
    SUM(dp_item_count)        AS 销量,
    SUM(dp_total_amount)      AS 流水
FROM tll_bi_dw.ads_dbs_trade_food_di
WHERE LEFT(business_date, 6) IN ('202511', '202611')
GROUP BY LEFT(business_date, 6), item_name
HAVING SUM(dp_item_count) > 0 OR SUM(dp_total_amount) > 0
ORDER BY 月份 ASC, 销量 DESC;

    导出为 data/各月产品销售.csv（脚本只读，不修改）。

    3.3 运行脚本#

    cd C:\Users\Administrator\OneDrive\Script\Monthly\food_sales
python main.py
    处理流程（全自动）
    各月产品销售.csv ──┐
                   ├─ enrich_csv()   商品名称 → 标准名称 / 类型
产品销售唯一值.xlsx ─┘
                         │
                         ▼
                  aggregate()        销量 < 100 → 归入 "其它 / 未匹配产品"
                         │
                         ▼
                  pivot_by_month()   宽表透视 + 打标签：
                                     两年均有 / {大月份}独有 / {小月份}独有
                                     按 标签 + 大月份销量 排序
                         │
                         ▼
                  sync_to_db()       TRUNCATE + executemany INSERT

    表结构随月份动态生成：本期 202611 比同期 202511 大 → 列名 202611销量 / 202611流水 / 202511销量 / 202511流水，标签自动写 202611独有 / 202511独有。

    3.4 校验#

    脚本末尾会打印标签分布，可大致核对：

    ✅ 已写入 XX 行 → Tianlala.food_sales_summary
标签分布:
两年均有       XX
202611独有     XX
202511独有     XX

    如果有大量产品被归为「其它 / 未匹配产品」，回去补 Step 3.1 的映射表。

    Step 4：刷新 Excel#

    1. 打开 {月份}月概览数据.xlsx
    2. 数据 → 全部刷新，三个 Power Query 查询依次从 MySQL 拉取
    3. 检查门店底表行数、产品底表行数是否合理

    Power Query 查询字段说明#

    门店底表派生列#

    主表 multi_period_channel_summary.全量数据（门店 × 期间 × 渠道汇总）LEFT JOIN shop_current。

    字段映射（shop_current 源字段 → 报表字段）：

    shop_current 报表
    门店编号 门店编号（连接键）
    门店名称 门店名称
    收银机ID 收银机ID
    省 / 市 / 区 省 / 市 / 区
    一级经理 省区经理
    二级经理 区域经理
    三级经理 督导
    战区 / 运营状态 战区 / 运营状态

    经理层级统一更名：一级 → 省区经理、二级 → 区域经理。

    派生列规则：

    列 规则
    是否存量门店 本期_汇总_流水 > 0 且 同期_汇总_流水 > 0 → 存量，否则非存量。空值安全
    销售周期 两期均有销售 / 本期有销售 / 同期有销售 / 两期均无销售
    合并状态 销售周期 + 是否存量门店 + 运营状态（便于核对）
    门店类型 编号 ZYD* → 直营店，TLL* → 加盟店
    职级标签 区域经理 = 督导 → 代管，否则督导
    标签判定顺序

    标签规则按条件自上而下匹配，先命中先生效：

    # 条件 标签
    1 运营状态 = 已解约_{同期年} 往期解约
    2 运营状态 = 已解约_{本期年} 本期解约
    3 销售周期 = 两期均有销售 存量门店
    4 销售周期 = 本期有销售 新增门店
    5 以上都不命中 本期未营业

    列序：维度列在前（门店编号、门店名称、省区经理、区域经理、督导、职级标签、战区、运营状态、收银机ID、省、市、区、门店类型、是否存量门店、销售周期、合并状态、标签），渠道指标列自动追加在后。

    产品底表#

    SELECT * FROM Tianlala.food_sales_summary，删除 created_at 列。脚本输出结构：

    列 类型 说明
    id INT AUTO_INCREMENT 主键
    标准名称 VARCHAR(100) 产品标准名
    类型 VARCHAR(50) 分类
    {本期}销量 BIGINT 如 202611销量
    {本期}流水 DECIMAL(14,2) 如 202611流水
    {同期}销量 BIGINT 如 202511销量
    {同期}流水 DECIMAL(14,2) 如 202511流水
    标签 VARCHAR(20) 两年均有 / {本期}独有 / {同期}独有

    唯一键 UNIQUE(标准名称, 类型)。排序：同期独有 → 两年均有（按本期销量降序）→ 本期独有。小销量归入：销量 < 100 → 标准名称改 其它、类型改 未匹配产品。

    维护提示#

    • 每月只需换 Excel 文件名 + 刷新，Power Query M 代码不变
    • 上游新增维度列（战区细分、新店级别等）：先在 multi_period_channel_summary 或 shop_current 加列，再在门店底表 M 代码的 ShopFieldMap 加一条
    • 产品侧新增月份：脚本自动识别、自动生新列、标签自动更新，SELECT * 自动跟上
    • 本期_ / 同期_ 开头的指标列已在 M 代码里强制转 number，避免上游类型漂移

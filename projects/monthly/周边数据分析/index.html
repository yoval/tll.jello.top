    周边数据分析#

    零食部门周边产品销售与报货数据分析：CSV 源数据经 Python 写入 MySQL，再由 Excel Power Query 经 ODBC 拉取生成报表。

    • 项目仓库：https://e.coding.net/fuwenyue/tianlala/snacks_sales.git
    • 数据依赖：
      • 中台导出三份 CSV：周边产品销售 / 周边产品报货 / 门店流水（查询 SQL 见下文）
      • 门店主数据 Tianlala.shop_current（门店信息管理 每日重建）

    数据流程#

    周边产品销售/报货/门店流水 CSV → Python 汇总合并 → MySQL
→ Excel Power Query（ODBC）关联门店主数据 → 报表

    数据表#

    zhoubian_data 库（Python 写入，详表 replace 全量重建）：

    表名 内容
    周边销售详表 各门店各产品销售明细
    周边报货详表 各门店报货明细
    门店销售 门店流水/实收/订单数/营业天数
    周边产品销量排名 按产品+月份汇总
    汇总表 三表按 门店+月份 合并

    运行方式#

    1. 三个源 CSV 放入 data/，执行 python main.py
    2. 打开当月 周边数据_YYYYMM.xlsx
    3. 首次使用需在 Excel 数据源设置中配置 ODBC 凭据（MySQL ODBC Unicode Driver，root/123456）
    4. 修改 .m 文件中 shared TargetMonth = YYYYMM; 后「全部刷新」

    源数据查询#

    通用注意事项
    1. 时间范围 2025-01-01 ~ 2025-12-31 是示例，实际查询时改为目标年份。
    2. 分区裁剪：shop_di / dwd_*_di 有 pt（varchar ‘yyyyMMdd’），food_di 只有 business_date（bigint yyyyMMdd）。必须加分区条件，否则全表扫。
    3. 日期转字符串：business_date 是 bigint，用 LEFT(CAST(business_date AS CHAR(8)), 6) 取月份，不要直接 LEFT(business_date, 6)（MySQL 隐式转换虽能跑但不严谨）。

    周边产品销售#

    来源：ads_dbs_trade_food_di（文档） 过滤条件：food_category_name IN ('周边产品', '周边') 营业天数：只有当日销量 > 0 才计入（产品售卖天数）

    -- 周边产品按门店 × 产品 × 月份汇总
SELECT
    stat_shop_id                                                          AS 门店编号,
    item_name                                                             AS 周边产品名称,
    LEFT(CAST(business_date AS CHAR(8)), 6)                               AS 月份,
    SUM(dp_item_count)                                                    AS 周边产品销量,
    SUM(dp_total_amount)                                                  AS 周边产品流水,
    -- 严格判断：只有当日销量 > 0 才计入售卖天数，避免零销量日污染
    COUNT(DISTINCT CASE WHEN dp_item_count > 0 THEN business_date END)   AS 产品售卖天数
FROM tll_bi_dw.ads_dbs_trade_food_di
WHERE business_date >= 20250101 AND business_date < 20260101   -- ✅ 分区裁剪（food_di 只有 business_date，没有 pt）
  AND food_category_name IN ('周边产品', '周边')
GROUP BY stat_shop_id, item_name, LEFT(CAST(business_date AS CHAR(8)), 6)
HAVING SUM(dp_item_count) > 0                -- 排除全年零销量的产品（减少 CSV 体积）
ORDER BY 门店编号, 周边产品名称, 月份;

    周边产品报货#

    来源：dwd_rps_tll_order_data_merge_di（文档） 周边筛选：sku_code LIKE '108%' 有效订单：order_status >= 3 AND order_status != 5（排除待支付和驳回）

    用 merge_di 单表查询，已合并头+详+已扣取消量，省一次 JOIN。

    SELECT
    store_code                                                     AS 门店编号,
    product_info                                                   AS 存货名称,
    LEFT(pt, 6)                                                    AS 月份,
    SUM(actual_num)                                                AS 周边报货数量,   -- 已扣取消量
    SUM(actual_num * discount_unit_price)                          AS 周边报货金额
FROM tll_bi_dw.dwd_rps_tll_order_data_merge_di
WHERE pt >= '20250101' AND pt < '20260101'   -- ✅ 分区裁剪
  AND order_status >= 3 AND order_status != 5
  AND sku_code LIKE '108%'
GROUP BY store_code, product_info, LEFT(pt, 6)
ORDER BY 门店编号, 存货名称, 月份;

    门店销售#

    来源：ads_dbs_trade_shop_pay_channel_di（文档） 门店筛选：shop_id LIKE 'TLL%' OR 'ZYD%'（甜啦啦主品牌 + 自有品牌） 营业天数：只有当日流水 > 0 才计入

    SELECT
    shop_id                                                          AS 门店编号,
    LEFT(pt, 6)                                                      AS 月份,
    SUM(amount)                                                      AS 门店流水,
    SUM(income)                                                      AS 门店实收,
    SUM(order_cnt)                                                   AS 门店订单数,
    -- 严格判断：只有当日流水 > 0 才计入营业天数
    COUNT(DISTINCT CASE WHEN amount > 0 THEN pt END)                 AS 门店营业天数
FROM tll_bi_dw.ads_dbs_trade_shop_pay_channel_di
WHERE pt >= '20250101' AND pt < '20260101'   -- ✅ 分区裁剪
  AND (shop_id LIKE 'TLL%' OR shop_id LIKE 'ZYD%')
GROUP BY shop_id, LEFT(pt, 6)
ORDER BY 门店编号, 月份;

    1. 三份查询结果保存为：周边产品销售查询.csv / 周边产品报货查询.csv / 门店流水查询.csv
    2. 放入项目仓库 data/ 目录
    3. 执行 python main.py 写入 zhoubian_data 库
    4. 打开当月 周边数据_YYYYMM.xlsx，修改 .m 文件中 shared TargetMonth = YYYYMM; 后「全部刷新」
